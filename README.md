# LTZ RPG Player for iOS

基于 Web 的 RPG 游戏播放器，支持 LTZ 自动翻译。

## 功能

- 加载 HTML5 游戏
- 响应式设计
- 支持 AI 翻译插件

## 构建 IPA

使用 GitHub Actions 自动构建：

1. 访问 https://github.com/kilo1235/LTZ-RPGPlayer-iOS/actions
2. 点击 "Build IPA" workflow
3. 点击 "Run workflow" 按钮
4. 等待构建完成
5. 下载 artifact: LTZ-RPG-IPA

## 安装

使用 i4 助手或 AltStore 进行侧载安装。
